# PDF 签名 Web 应用

手机端 PDF 手动签名工具。完全在浏览器本地处理，文件不上传服务器。

## 功能

- 上传本地 PDF 并预览（支持多页）
- 在预览页面上拖动创建签名区，可调整大小、移动、删除
- 点击签名区进入全屏横屏签名模式（带撤销/清空/确认）
- 确认后签名渲染回签名区，所见即所得
- 一键导出已签名 PDF

## 技术栈

- React 18 + Vite + TypeScript
- Tailwind CSS
- pdfjs-dist（PDF 渲染）
- pdf-lib（PDF 修改/导出）

## 启动

```bash
npm install
npm run dev
```

启动后 Vite 会打印所有可访问的 URL，包括：

```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

## 手机调试

1. 确保手机和电脑连接**同一 WiFi**（或同一局域网）
2. 在手机上访问 `Network` 后面的 URL（如 `http://192.168.1.100:5173/`）
3. 修改代码后 Vite 会自动热更新，手机端立即生效

## 使用流程

1. **上传 PDF** — 点击"选择 PDF 文件"或将文件拖拽到上传区
2. **创建签名区** — 在 PDF 预览上按住拖动，拖出一个矩形
3. **调整签名区** — 点击签名区选中后，可拖动移动或拖控制点调整大小；上方浮窗有"删除"按钮
4. **签名** — 点击"签名"按钮进入全屏签名模式（手机会自动锁定横屏）
5. **手写签名** — 任意画布位置可写；"撤销"删除最后一笔，"清空"清空画布
6. **确认** — 签名渲染回签名区位置；点击"重新签名"可重做
7. **导出** — 顶部"导出签名 PDF"按钮，下载合并签名后的 PDF

## 已知限制

- iOS Safari 不支持 `screen.orientation.lock()`，需用户手动旋转手机至横屏
- 加密 PDF 不支持
- 单签名区（v1）；如需多签名区请删除现有签名区后再次拖动创建

## 浏览器兼容性

- iOS Safari 15+
- Android Chrome 100+
- Desktop Chrome / Firefox / Safari（辅助调试）
